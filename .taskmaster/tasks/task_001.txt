# Task ID: 1
# Title: Setup React Native Project with Expo
# Status: pending
# Dependencies: None
# Priority: high
# Description: Initialize the React Native project using Expo and configure expo-router for navigation, establishing the foundation for the GolfGames migration.
# Details:
1. Install Expo CLI: `npm install -g expo-cli`
2. Create new project: `npx create-expo-app GolfGames --template expo-template-blank-typescript`
3. Install expo-router: `npx expo install expo-router react-native-safe-area-context react-native-screens expo-linking expo-constants expo-status-bar`
4. Configure app directory structure for expo-router:
   - Create `app/` directory
   - Set up `app/_layout.tsx` for root navigation
   - Create initial route files (index.tsx, login.tsx, etc.)
5. Update app.json with proper app identifiers and permissions
6. Configure TypeScript settings in tsconfig.json
7. Set up environment configuration for development/production
8. Test basic navigation between screens

# Test Strategy:
1. Verify project builds successfully on iOS and Android simulators
2. Test navigation between basic screens
3. Confirm hot reloading works properly
4. Validate TypeScript configuration
5. Ensure Expo development tools are functioning
